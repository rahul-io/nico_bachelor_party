# Nico's Bachelor Party

Mobile-first web app for the weekend: schedule, sobriety tracker, leaderboard, photo feed, admin.

```bash
npm install
npm run dev
```

Runs on mock data with no setup. Copy `.env.example` to `.env.local` to connect real services.

See [plan.md](plan.md) for milestones and [CLAUDE.md](CLAUDE.md) for stack and conventions.
